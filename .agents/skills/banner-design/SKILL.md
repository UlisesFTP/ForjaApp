# Banner Design · FORJA

Solo para banner/cover/promoción encargado, no para añadir cabecera grande a Hoy. Leer brand-guidelines y dimensión/contenido pedidos; usar contexto sin repetir preguntas resueltas.

Un mensaje principal, acción clara si corresponde y logo legible; monocromo/fuentes/safe zones/contraste. Variantes si ayudan a la solicitud. No copiar assets/contenidos protegidos.

[Original](references/original/SKILL.md) y [tamaños/estilos](references/original/references/banner-sizes-and-styles.md). Se conserva licencia MIT/atribución del original.

Skills ai-artist/ai-multimodal/frontend-design no incluidas. Usar herramientas disponibles para crear/exportar. Para vectores existentes preferir recursos nativos. Sin exporter, entregar fuente y limitación, no declarar PNG verificado inexistente.

Verificar dimensiones/recorte/logo/texto/procedencia y guardar asset. Actualizar docs si cambia identidad/campaña. No autoriza publicar campañas.
